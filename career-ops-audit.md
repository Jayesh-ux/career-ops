## THE CORE WORKFLOW (what kept you applying)

```
1. SCAN     → scan.mjs hits 86 company APIs + 25+ search queries
2. EVALUATE → auto-pipeline scores each JD 1-5, generates report
3. APPLY    → system drafts email with CV, you confirm, it sends
4. TRACK    → application added to tracker with status
5. REPLY    → system drafts recruiter responses using your profile
6. REPEAT   → scan finds new roles daily, pipeline processes them
```

The main logic: **your CV + profile never change** — the system reads them fresh for every role and reframes your experience to match each JD. You just paste URLs or say "scan" and it does the rest.
